Ask the Sheet: iNViSU reads the Library of Congress drawings

Preservation architects, historians and the people who maintain historic buildings answer one question by reading hand-lettered drawings sheet by sheet. Ask the Sheet lets them type "where is the throne room" and get the answer with the plan sheet as a clickable receipt, the lettering it relied on boxed on the drawing, and a reader that says "not in the set" when the set does not say. It runs on NVIDIA Nemotron through Nebius: Nemotron 3 Nano Omni reads the scans on a Nebius AI Cloud Serverless endpoint, Nemotron 3 Ultra reasons over the index on Nebius Token Factory.

Why. The Library of Congress holds about 55,000 public-domain documentation sets of American buildings: scans of hand-lettered measured drawings, survey photographs, typed data pages. None can be asked a question: no text layer, lettering by hand, cross-references that are words on the sheet ("SEE SHEET 12"), not links.

What it does. Demo set: Iolani Palace, Honolulu (HABS HI-1, loc.gov hi0047), 85 pages, 23 scanned sheets from the 1964-66 survey, 57 photographs. "What does HABS sheet 12 reference" turns the cross-reference lettering into the receipt. A question the set cannot answer returns NOT IN THE SET with the pages it checked. Four outcomes exist: answered with receipts, answered from memory with its date, not in the set, unknown entity. Receipts are verified in code in two steps: a cited page must exist in the index, and every span the answer quotes must appear on a cited page, or the answer is marked unverified with the missing quote named. Numbers, dates and sheet numbers are never estimated.

How it works. One OpenAI-compatible client, every call to Nebius, every model an NVIDIA Nemotron open model. A chained, unattended workflow with no human between the loc.gov download and the answered question: ingest; full-sheet read; quadrant re-read for small lettering; dedupe; typed "SEE SHEET N" references mapped through each sheet's own "SHEET N OF 22" lettering; a SQLite index that records every reference whose target is missing; an evidence pack per question (inventory, typed links, term hits, full page text under a budget); the brain's answer in one of the four outcomes; the two receipt checks; a second call if the model skips its outcome line.

What ran. Nano for the reads, Ultra for the reasoning, both Nebius surfaces, one client. Eyes: nvidia/Nemotron-3-Nano-Omni-30B-A3B-Reasoning-FP8 on one NVIDIA L40S, stock vLLM image: 23 of 23 sheets, 1,818 text entries, 23 titles, 47 typed cross-references, 7 unresolved (all a sheet 22 this record lacks), 124 minutes, about $1.59. Brain, in the video: nvidia/Nemotron-3-Ultra-550b-a55b on Token Factory, median 4.7 s per 30,000-token question, reasoning returned separately, every receipt verified. Nemotron-3.5-Super-VL read the same 23 sheets on Token Factory as a comparison, scored on the same metric and kept in the repository: a measurement, not a ranking.

Second set: Lahaina. On August 8, 2023 the wildfire burned three HABS-measured buildings to their walls: the Old Lahaina Courthouse (1859, 8 sheets), the Master's Reading Room (1834, 5 sheets), Hale Aloha Church (1858, 6 sheets). The same pipeline, unchanged, read all three on Token Factory, 1,725 entries, each with its own static demo and transcripts. Ask the courthouse drawings what the walls are built of: "ORIGINAL CORAL WALLS 21\" THICK", with the sheet as receipt, the walls that stood. Ask what happened in 2023 and the reader says NOT IN THE SET: the drawings end in 1966.

Built during the Submission Period. The page index and cross-reference check descend from our public PlanGraph repository (MIT, August). Everything else was built October 27-28: the Nemotron reader and quadrant pass, the four-outcome agent with receipt and quote verification, the evidence pack, the app and Space, both platform runs, the reader comparison and the video recorder.

Found by reading the model's output, not the logs: a repetition loop at temperature 0, a bare JSON array the first parser dropped as "+0", boxes mixing pixel and fraction scales, inline reasoning without a parser, a brain that read a reference backwards until the pack named each link's direction. All handled in code.

Limits. Two sets, four records; a county-scale batch is the next step. The public Space answers sixty questions a day; the local app has no cap. Small lettering can be missed at 1,400 px. Boxes point at lettering. A verified page is not a verified reading. English only.

Next. A batch runner over loc.gov record IDs so a preservation office can point at its county and get every set answerable. Fine-tune Nemotron-Nano-V2-12B VL on Token Factory on our 228,000-box drawing-text corpus. Then iNViSU Spatial Memory verified by MAG, so answers a human confirmed are remembered across sets.
